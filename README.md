This is the evaluation repository for the paper "The Harsh Truth about Reentrancy Detection in Smart Contracts" submitted at ATC 2026 on June 10th, 2026.
The `dataset` folder contains the handcrafted dataset for multiple Solidity versions.
The `test_environment` folder contains Hardhat scripts and attacker contracts to verify the dataset.
The `resuts` folder contains results in CSV format both for the tools included in the Smartbugs suite and those not included.
